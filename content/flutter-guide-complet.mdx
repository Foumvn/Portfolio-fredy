# Flutter : Guide Complet pour Développer des Applications Multiplateformes

Flutter est bien plus qu'un framework — c'est une révolution dans la façon de concevoir des applications. Avec un seul codebase Dart, vous ciblez iOS, Android, Web, macOS, Windows et Linux.

> "Flutter vous permet d'écrire une fois et d'exécuter partout, sans sacrifier la performance ni l'expérience utilisateur."

## Pourquoi choisir Flutter ?

### Avantages clés

- **Hot Reload** : Voyez vos modifications en temps réel sans recompilation
- **Performance native** : Compilation AOT vers du code machine
- **Widgets personnalisables** : Un système de widgets riche et flexible
- **Communauté active** : Des milliers de packages sur pub.dev
- **Support multi-plateforme** : 6 cibles avec un seul codebase

## Architecture Flutter

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Mon App Flutter',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.blue),
        useMaterial3: true,
      ),
      home: const HomeScreen(),
    );
  }
}
```

### Widgets Fondamentaux

| Widget | Rôle | Exemple d'usage |
|--------|------|-----------------|
| `Container` | Boîte de base avec décoration | Arrière-plan, marges, padding |
| `Row` / `Column` | Disposition horizontale / verticale | Mise en page flexible |
| `Stack` | Superposition de widgets | Calques, overlays |
| `ListView` | Liste défilante | Fil d'actualité, résultats |
| `GridView` | Grille d'éléments | Galerie, grille de produits |

## Gestion d'État

### Provider (Recommandé pour débuter)

```dart
class CounterProvider extends ChangeNotifier {
  int _count = 0;
  int get count => _count;

  void increment() {
    _count++;
    notifyListeners();
  }
}

// Utilisation
final counter = context.watch<CounterProvider>();
Text('${counter.count}');
```

### Pourquoi Provider ?

- **Simple à comprendre** : Pas de courbe d'apprentissage abrupte
- **Intégré à Flutter** : Utilise `InheritedWidget` nativement
- **Scalable** : Suffisant pour des apps de taille moyenne

## Navigation avec GoRouter

```dart
final router = GoRouter(
  routes: [
    GoRoute(path: '/', builder: (_, __) => const HomeScreen()),
    GoRoute(
      path: '/details/:id',
      builder: (_, state) => DetailScreen(id: state.pathParameters['id']!),
    ),
  ],
);
```

## Performance

| Technique | Gain |
|-----------|------|
| `const` widgets | Évite les reconstructions inutiles |
| `RepaintBoundary` | Isole les parties qui changent |
| `ListView.builder` | Construction paresseuse des items |
| `ImageCache` | Cache natif des images |

## Déploiement

1. **Android** : `flutter build apk` ou `flutter build appbundle`
2. **iOS** : `flutter build ios` (nécessite Xcode)
3. **Web** : `flutter build web`
4. **Desktop** : `flutter build linux`, `flutter build windows`, `flutter build macos`

## Conclusion

Flutter n'est pas juste un framework mobile — c'est une plateforme complète qui couvre tous les écrans. Que vous débutiez ou que vous veniez du monde natif, Flutter vous offre la puissance et la flexibilité nécessaires pour donner vie à vos idées.

Commencez petit, maîtrisez les bases, et construisez des applications qui tournent partout.
