La performance n'est pas optionnelle — c'est une fonctionnalité. Voici des astuces éprouvées pour optimiser les apps Next.js.

## 2. Optimisez les Images

Utilisez toujours `next/image`

```tsx
import Image from 'next/image';

export function Hero() {
  return (
    <Image
      src="/hero.jpg"
      alt="Image hero"
      width={1200}
      height={600}
      priority // Chargement immédiat pour le LCP
      placeholder="blur"
      blurDataURL="data:image/jpeg;base64,..."
    />
  );
}
```

## 4. Implémentez un Cache Approprié

| Stratégie | Cas d'usage | TTL |
|-----------|-------------|-----|
| `force-cache` | Données statiques | Illimité |
| `revalidate: 3600` | Semi-statique | 1 heure |
| `revalidate: 60` | Mises à jour fréquentes | 1 minute |
| `no-store` | Temps réel | Jamais de cache |

## 5. Minimisez les Composants Client

Chaque directive `'use client'` alourdit votre bundle JavaScript. Gardez les composants clients petits et ciblés.

## 6. Analyse du Bundle

```bash title="terminal"
# Installer l'analyseur
npm install @next/bundle-analyzer

# Lancer l'analyse
ANALYZE=true npm run build
```
